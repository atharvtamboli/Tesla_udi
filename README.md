# TESLA CARBON 

**A browser-based 3D stunt driving simulator built with Three.js, HTML, CSS, and vanilla JavaScript.**

Customize your car, explore challenging stunt arenas, perform jumps and aerial tricks, and test your driving skills through different physics modes.

## Features

- **Five stunt arenas:** Curl Wall, Mega Tower, Speed Kicker, Car Jump, and Hyper Loop 360°
- **3D car customization:** Paint, wheels, aerodynamics, and visual details
- **Vehicle tuning:** Adjust performance characteristics from the garage
- **Three physics modes:** Pro, Hyper, and Low-G
- **Driving mechanics:** Thrust, nitro, airbrake, aerial flips, hop, and precision controls
- **Interactive garage:** Preview the car and customize its setup
- **Camera controls:** Switch views and inspect your car
- **Responsive controls:** Keyboard and on-screen touch controls
- **Performance feedback:** Game statistics, scores, and personal records

## Controls

| Key | Action |
|---|---|
| W / Space | Thrust |
| Shift | Nitro |
| Left / Right Arrows | Flip / Vector |
| B / Ctrl | Airbrake |
| H | Hop / Cushion |
| Q + Arrow Keys | Flip Burst |
| Alt | Precision Trim |
| Down Arrow / S | Gyro Level |
| E / F | Bullet Focus |
| C | Change Camera |
| R | Retry |

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/tesla-carbon-3d.git
   ```

2. Open the project folder.

3. Open `index.html` in a modern browser.

Alternatively, use a local development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

An internet connection is required for CDN-hosted Three.js and Google Fonts.

## Deployment

The game is deployed as a static website using Vercel.

To deploy your own version:

1. Fork or clone this repository.
2. Import the repository into Vercel.
3. Select the **Other** framework preset.
4. Deploy without a custom build command.
